# Goose Zed Extension

This extension adds support for [Goose](https://github.com/aardappel/goose) programming language to [Zed](https://github.com/zed-industries/zed) editor.

Specifically for this extension, a fork of the Goose repository just for the [tree-sitter](https://github.com/RomanPro100/goose-tree-sitter) was made.

## Prerequisites

In order for the extension to work, you must have `goose` installed and available in your `PATH`.
